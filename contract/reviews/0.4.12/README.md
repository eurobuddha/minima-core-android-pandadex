# PandaDEX 0.4.12 — pool-inclusive market history

The public last-trade price, tape and chart now include verified executions at known PandaPools MINIMA/MxUSD covenants, including another wallet's trades. Execution price is the actual token reserve delta divided by the MINIMA delta for each contract-enforced pair. Liquidity additions, withdrawals, maintenance and unrelated pool donations are excluded. Personal trade receipts remain separate.

Reuse: PandaPools PoolActivity / TxClassifier opposite-sign reserve flows; PandaDEX DexHistory bounded public pager, ChainEvidence inclusion-block verification, DexDb chaincheck revision/proof guards. No unbounded address-history query. Schema 13 → 14 only adds marketpool/pooltrade and their index; original records are retained. Reorg/missing proof removes a pool trade from the current market view while preserving its original record for correction.

Validation: 696 JVM tests, zero failures/errors/skips; lint zero errors, 74 warnings. Android audit 41: 853 normal + 16 pre-crash + 31 recovery + 128 full offline Activity assertions = 1,028. Tested real SQLite upgrade, pool/limit latest selection, duplicate suppression, missing/moved proof, immutable original timestamps and rollback on failed persistence. Audit 39 failed compilation in a new fixture (long count assigned to int); audit 40 stopped at the fixture's table allowlist. Both corrected in audit 41; previous APKs/evidence retained.

Limits: only known validated pool addresses and history still retrievable from the connected node can be observed. Public scans are bounded and need multiple passes; this is not an exhaustive historical index. Trades sharing an inclusion-block timestamp use a stable identifier tie-break, not a claimed intra-block execution ordering. Samsung live observation of someone else's PandaPools trade remains a stock-device check. No funded transaction was executed by this review; no production APK built, pushed or published here. Keepalive/covenant expiry and renewal unchanged.
