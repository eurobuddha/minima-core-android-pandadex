# PandaDEX 0.4.13 — transaction feedback and keyboard layout

The real transaction path reports wallet selection, pool access, signing-slot wait, construction, signing, validation and node submission. Node acceptance retains the existing confirmation/recovery callbacks. It is never labelled on-chain merely because submission returned. The latest three entries are visible; tap for the bounded 60-entry log. Logs survive Activity recreation. An active status no longer expires after 45 seconds.

Keyboard insets resize the usable form area above the IME. In landscape, the header/navigation temporarily make room and the log compacts; normal navigation returns when the keyboard closes. Existing input values and Samsung-compatible decimal input behavior are preserved. Execute dismisses the keyboard. The log and keyboard changes introduce no trade-eligibility restriction: the initially proposed additional pending-trade button lock was removed at the user's instruction. The pre-existing Execute awaitingFill check remains unchanged; changing that older singleton receipt model was asked about separately and is not included here. GTC covenant/expiry/renewal behavior is unchanged.
